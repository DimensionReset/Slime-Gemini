## Installation
Before you begin, please note that **Side B** of step one is for those who can't install the extension normally due to administrative restrictions. If you use your personal account for platform use, feel free to skip **1B** of the following steps:
  1. Add the browser extension to your account.  
     1A. Install the extension via the [**Chrome Web Store page**](https://chromewebstore.google.com/detail/nepbfhnjfncikkfokmiliinlgdakjjbm?utm_source=item-share-cb).  
     1B. Unpack the extension using [**this extension**](https://chromewebstore.google.com/detail/ajkhmmldknmfjnmeedkbkkojgobmljda?utm_source=item-share-cb) or similar, then [repack it into your account as developer](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked).  
  2. Customize browser extension settings.  
     - Flick the switch to send the goons.
